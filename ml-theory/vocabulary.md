# ML/AI-Related Vocabulary

- loss function:
  - measures how wrong a *single* prediction
  - example: loss=(prediction − actual)^2 = (8−5)^2 = 9
- cost function:
  - the aggregate (average or sum) of the loss function over all data points.
  - this is what we're trying to optimize
- objective function:
  - the thing you're optimizing. Usually the same as the cost function, BUT it can include extra terms like regularization.
